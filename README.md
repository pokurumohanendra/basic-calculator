# The Unconventional Calculator

A minimal calculator built with HTML, CSS and vanilla JavaScript. Enter a number, choose an operation, and see the running calculation and result.

**Live demo:** [pokurumohanendra.github.io/basic-calculator](https://pokurumohanendra.github.io/basic-calculator/)

## Features

- Add, subtract, multiply and divide
- Shows the current calculation and the result
- Records each calculation in a log (printed to the browser console)

## Tech stack

HTML, CSS and JavaScript. No build step or dependencies. Hosted on GitHub Pages.

## Getting started

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Project structure

```
index.html
assets/
├── scripts/app.js   input handling and calculation
└── styles/app.css
```

## About

Built as a learning project to practise functions, event listeners and basic DOM updates in plain JavaScript.
